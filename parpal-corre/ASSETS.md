# Imágenes y marca

## Logo

Archivo: `assets/parpal-logo.svg`.

Origen: web corporativa https://parpalco.com/; recurso original https://framerusercontent.com/images/JQ2whr2d31GgvEXpH1a62WZE82Q.svg.

Se conserva el archivo original. El encabezado muestra el escudo mediante recorte de presentación CSS y el nombre con texto. El uso de la marca corresponde a PARPAL.

## Carrusel de portada

Archivo: `assets/equipo-carrera-01.jpeg`.

Origen: fotografía real `PARPAL RUN.jpeg` suministrada por el usuario. Es una copia exacta del archivo original, sin regeneración con IA, sin retoques de rostros, cuerpo o poses. La presentación con fondo oscuro y ajuste de tamaño se hace mediante CSS y no modifica el archivo.

La imagen ilustrativa generada para la primera versión ha sido reemplazada. La edición generativa rechazada no forma parte de este paquete.

Para incluir más fotos, edita `photos.js`. El README contiene un ejemplo con dos fotos.
